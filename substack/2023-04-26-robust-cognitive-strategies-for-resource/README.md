# Robust Cognitive Strategies for Resource-Rich Minds

**Source:** [bengoertzel.substack.com/p/robust-cognitive-strategies-for-resource](https://bengoertzel.substack.com/p/robust-cognitive-strategies-for-resource)
**Date:** 2023-04-26

## Summary

Explores how minds with vastly greater computational resources than humans should allocate those resources for robust cognition. Argues for strategies involving massive parallelism, speculative execution of reasoning paths, and maintaining diverse cognitive approaches simultaneously rather than committing to single strategies.

## Hyperseed Ontology Interpretation

the fiber bundle of cognitive strategies over the base of available resources has a phase transition at the resource-abundance frontier; the d-calculus connection for resource-rich minds involves parallel transport along multiple simultaneous sections rather than a single path
